# CombustionLens demo

## Run the self-contained explorer

From `frontend`, run `npm ci`, then `npm run dev`. Open the localhost URL printed by Vite. The landing explorer needs neither an API key nor the Python backend. NASA source links require internet access.

For the research API, follow the root README installation and corpus ingestion steps. Ask, Compare and Safety Brief depend on that backend and its data. Do not describe the four explorer cards as a populated numerical dataset or an evaluated AI system.

## Three-minute walkthrough

1. Open Explore. Frame the problem: finding a combustion result is not enough; a researcher needs to know whether its conditions apply to a mission.
2. Select Orbital habitat and prioritize Detection & extinction. FLEX moves to the top. Read the NASA observation, then the separate team interpretation.
3. Expand its boundary: droplet behavior cannot automatically establish solid-material behavior. Open its NASA source.
4. Switch to Lunar surface. Show the explicit partial-gravity evidence gap. The system does not fabricate a lunar safety threshold.
5. Add FLEX and another card to the brief. Download the Markdown brief; show that citations, limitations and mission context travel with the findings.
6. Search for `regolith`. Show that no matching evidence produces an empty state rather than an invented conclusion.
7. Explain the next layer: the existing literature retrieval and verified experiment comparator require a curated corpus, calibration and evaluation before their results can be demonstrated as validated.

## Accurate project description

CombustionLens is a research prototype combining a source-linked NASA mission explorer with a backend architecture for grounded literature retrieval and guarded experimental comparisons. The explorer ranks four curated campaign summaries using a disclosed deterministic method, separates observations from interpretations, and exports research briefs with evidence gaps. It is not a validated fire risk model or flight safety system.
